# Projetos 🚀


## 🏠 Imov.Plan

Plataforma full-stack para planejamento e simulação de compra de imóveis, criada para substituir planilhas financeiras por uma solução inteligente de organização e tomada de decisão.

A aplicação permite simular financiamento imobiliário, analisar capacidade de compra, compor renda entre participantes e acompanhar o planejamento financeiro para aquisição de imóveis.

### Principais funcionalidades:
- Simulação de financiamento imobiliário
- Cálculo de capacidade de compra
- Composição de renda familiar
- Planejamento financeiro personalizado
- Simulações de investimentos
- Autenticação de usuários
- Interface responsiva e mobile-first

### Stack:
**Frontend**
- Next.js
- TypeScript
- React
- Tailwind CSS
- Context API
- React Hook Form
- Zod

**Backend**
- C#
- ASP.NET Core .NET 9
- MongoDB
- JWT Authentication

**Infraestrutura**
- Docker
- AWS
- Deploy Cloud

Site:
https://imov-plan.vercel.app/

GitHub:
